# The One-Line Exit

Competition: `u-kreutzx-the-one-line-exit-1dc652d1` (make.fun)

## What this does

`main.py` (Python 3.13, no network, no input files) writes exactly one funny
one-line resignation letter to `/output/entry.txt`:

> I resign — I was hired to teach the new AI, and it just wrote my resignation letter better than I could, so here it is.

119 characters, one line, UTF-8. The letter is its own punchline: an AI trainer
out-written by the thing he trained.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
